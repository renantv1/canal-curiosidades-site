Política de Privacidade

Privacy Policy — Canal Curiosidades (last updated: 14 Nov 2026)

1. Quem somos / Who we are

Canal Curiosidades é um aplicativo de uso pessoal, sem outros usuários, mantido por Renan Rocha. Ele serve apenas para publicar vídeos curtos educativos no próprio canal do YouTube do desenvolvedor e ler as estatísticas desse mesmo canal.

Canal Curiosidades is a personal, single-user application. It is used only to upload short educational videos to the developer's own YouTube channel and to read statistics of that same channel.

2. Serviços de API do YouTube / YouTube API Services

O aplicativo usa os Serviços de API do YouTube (YouTube Data API v3) e, por isso, ao usá-lo você concorda com os Termos de Serviço do YouTube. O uso dos dados segue a Política para Desenvolvedores dos Serviços de API do YouTube.

This application uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service.

3. Política de Privacidade do Google / Google Privacy Policy

Os dados tratados pelo Google ao usar o YouTube são regidos pela Política de Privacidade do Google.

Data handled by Google when you use YouTube is governed by the Google Privacy Policy.

4. Dados acessados, armazenados e compartilhados / Data accessed, stored and shared

  • Escopos usados: youtube.upload (enviar vídeos ao próprio canal) e youtube.readonly (ler estatísticas do próprio canal).
  • O aplicativo não coleta, vende nem compartilha dados de visitantes ou de terceiros. Ele não tem outros usuários.
  • O token de autorização do YouTube e as estatísticas lidas ficam armazenados somente no computador do desenvolvedor. Nada é enviado a servidores de terceiros.
  • O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Retenção e exclusão de dados / Data retention and deletion

Os tokens e as estatísticas são mantidos apenas enquanto o aplicativo estiver em uso e são apagados do computador quando o acesso é encerrado. Para pedir a exclusão de qualquer dado, escreva para o contato abaixo; o pedido é atendido em até 30 dias. Os dados armazenados pelo Google são geridos pelo Google.

Tokens and statistics are kept only while the application is in use and are deleted from the computer when access ends. To request deletion of any data, contact us below; requests are handled within 30 days.

6. Revogar o acesso / Revoking access

O acesso do aplicativo à conta Google pode ser revogado a qualquer momento em myaccount.google.com/permissions e na página de configurações de segurança do Google. Após a revogação, o aplicativo deixa de acessar o YouTube e os dados armazenados são apagados.

You can revoke the application's access at any time at Google security settings.
