Política de Privacidade

O aplicativo Canal Curiosidades é de uso pessoal do dono do canal e usa a YouTube Data API v3 apenas para enviar vídeos ao próprio canal.

Dados coletados

Não coletamos, vendemos nem compartilhamos dados de visitantes ou de terceiros. O aplicativo não tem outros usuários.

Dados armazenados

O token de autorização do YouTube fica guardado somente no computador do dono do canal e é usado apenas para enviar vídeos.

Serviços do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
